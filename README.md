# redcorn
Project RedCorn

An audio player that is designed for you to enjoy music intentionally. Modern audio players have taken the essence out of music, and it feels more like an algorithm at work. Project RedCorn will make it so every time you boot up your FLAC file, you want to not only listen to music but really live it.
Some Features:
There is no resampling, the audio will be played as it was intended.
No Hidden EQ or normalization applied
Album Focused, when an album ends, the user will have to load the next album, 
Album artwork has been disregarded, but it is the essence of the album.
